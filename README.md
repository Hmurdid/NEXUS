Made by Kostia. A school project as multifunctional device on ESP32:
* Own Shell for all functions and cusomisation
* Code with full module independence
* Sensors, 12-pad controll keyboard, RGBLED 
* Applications such as game (pong), calc, humidity & temp reader with graph, light, loudmeeter and others.

NEXUS combines many functions, which is why its name is related to neurons. 
The project was never completed and is unlikely to be finished—the plan was 
for it to be a full-fledged Game Boy capable of running ported NES games, 
but even so, it was an overkill project for a mere “school” project.
